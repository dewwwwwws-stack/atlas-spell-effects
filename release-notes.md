## New name: Combat+ for Atlas VTT

**Spell Effects for AtlasVTT is now Combat+ for Atlas VTT**, since it now does attacks and rolling as well as spell effects. It's the same plugin: you don't need to reinstall, and your settings, saved spells and folders stay as they are.

- The settings page, messages and README use the new name.
- The plugin's description now mentions the optional D&D 5e rolls.
