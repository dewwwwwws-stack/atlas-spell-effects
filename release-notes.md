## What's new

- **Tokens' bars, nameplates and handles show through lasting spells** (not only the token itself), with soft edges.
- **More light settings…** in a spell's edit window opens Atlas's own light editor on the spell's light: colour, beam, intensity, softness, flicker and the rest. What you set there stays with the spell (also when you move it), and **Reset** puts it back.
- A spell's light can no longer drift away from the spell: if it's moved apart, it's put back.
